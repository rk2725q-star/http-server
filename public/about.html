About NetServe

Architecture, Networking Principles & Implementation Details

1. Project Vision & Purpose

NetServe is a custom-built, production-grade HTTP/1.1 web server implemented entirely from ground zero using Python's low-level socket and threading libraries. Modern web developers frequently use high-level abstractions like Flask, Django, FastAPI, Express, or Nginx without understanding how TCP connections are accepted, how byte streams are parsed into HTTP headers, or how concurrent connections are scheduled across OS threads.

NetServe demystifies the network stack by providing a transparent, educational, and fully functional implementation of the HTTP protocol on top of TCP/IP.

2. Core Networking Concepts Demonstrated

🔌 1. TCP Sockets & Port Binding

Uses socket.socket(AF_INET, SOCK_STREAM) with SO_REUSEADDR to create a reliable, ordered, connection-oriented byte stream on a specific TCP port.

self.server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
self.server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
self.server_socket.bind((self.host, self.port))
self.server_socket.listen(100)

📡 2. HTTP/1.1 Request/Response

Manually reads byte chunks, locates the CRLF header boundary (\r\n\r\n), extracts headers, validates methods (GET, HEAD), and crafts compliant HTTP/1.1 response bytes.

HTTP/1.1 200 OK\r\n
Date: Wed, 19 Aug 2026 16:35:00 GMT\r\n
Server: NetServe/1.0.0\r\n
Content-Type: text/html; charset=utf-8\r\n
Content-Length: 2048\r\n
Connection: keep-alive\r\n\r\n
[Payload Bytes...]

⚡ 3. Thread Pool Concurrency

Handles multiple concurrent clients without blocking the main server loop using ThreadPoolExecutor, tracking active worker threads and connection lifecycles.

self.executor = ThreadPoolExecutor(max_workers=8)
while self.running:
    client_sock, client_addr = self.server_socket.accept()
    handler = ClientHandler(client_sock, client_addr)
    self.executor.submit(handler.handle)

📊 4. Real-Time Telemetry & Monitoring

Thread-safe telemetry engine tracking requests/minute, latency distributions, status code breakdowns (2xx, 3xx, 4xx, 5xx), peak concurrency, and structured access logging.

monitor.record_request(RequestRecord(
    timestamp=time.time(),
    client_ip=client_ip,
    method="GET",
    path="/api/stats",
    status_code=200,
    response_size=1024,
    duration_ms=1.8
))

4. Security Safeguards

  • Directory Traversal Shield: Canonical path resolution rejects attempts to escape public directories (e.g. ../../etc/passwd).
  • Request Size Caps: Rejects payloads exceeding 1MB (413 Payload Too Large) to prevent buffer starvation.
  • Header Limits: Maximum header size (8KB) and maximum header count (100) guards against Slowloris-style header attacks (431).
  • Method Whitelist: Only allows specified HTTP methods (GET, HEAD), rejecting unsupported methods with 405 Method Not Allowed.
  • Connection Timeout: Closes inactive TCP sockets after 30 seconds of inactivity to reclaim worker threads.

5. Demonstration & Educational Value

NetServe serves as a comprehensive reference implementation for undergraduate Computer Networks courses. Every metric rendered on the dashboard, every line in server.log, and every byte delivered across the TCP socket is computed natively without external third-party frameworks.
