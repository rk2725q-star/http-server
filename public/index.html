TCP Socket Server

Built with raw Python socket.socket(AF_INET, SOCK_STREAM). Configurable host, port, SO_REUSEADDR, and connection accept loop.

📡

HTTP/1.1 Parser

Manual stateful parsing of request lines, headers, query parameters, method validation (GET/HEAD), and payload body limits.

⚡

Multi-Threaded Workers

Non-blocking concurrency using ThreadPoolExecutor. Supports simultaneous clients, persistent Keep-Alive connections, and socket timeouts.

📊

Real-Time Telemetry

Thread-safe monitoring tracking requests/min, latency distributions, status code breakdown, active clients, and formatted access logging.

REST-like Telemetry JSON APIs

GET /api/status

Returns server identity, bind host, listening port, uptime, and active connection count.

GET /api/stats

Returns cumulative request counts, average latencies, data throughput, and status code distributions.

GET /api/requests

Returns the ring buffer of recent HTTP requests with client IPs, methods, routes, and response times.

GET /api/network

Returns host IP addresses, listening socket details, peak client concurrency, and network statistics.

GET /api/logs

Returns recent structured access logs directly from logs/server.log.
